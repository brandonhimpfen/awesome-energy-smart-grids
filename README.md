> A curated list of resources for smart grid technology, power system simulation, renewable energy integration, energy management systems (EMS), and microgrid control.

Smart energy grids integrate digital communication networks, distributed energy resources (DERs), smart metering infrastructure (AMI), and advanced optimization algorithms to deliver reliable, efficient, and decarbonized power systems. This list is intended for power system engineers, energy data scientists, smart grid developers, and grid resilience researchers.

## Power System Simulation & Modeling

Open-source simulation frameworks, power flow solvers, and dynamic grid analysis tools.

- [PyPSA (Python for Power System Analysis)](https://github.com/PyPSA/PyPSA) — Open-source toolbox for simulating and optimizing modern power systems with high penetrations of renewable energy.
- [Pandapower](https://github.com/e2ncls/pandapower) — Open-source Python tool for power system modeling, analysis, and optimization combining pandas and PYPOWER.
- [GridLAB-D](https://github.com/gridlab-d/gridlab-d) — Flexible power system simulation tool developed by PNNL for analyzing distribution systems and smart grid technologies.
- [MATPOWER](https://github.com/MATPOWER/matpower) — Open-source MATLAB/Octave toolbox for solving power flow, optimal power flow, and unit commitment problems.

## Energy Management Systems (EMS) & SCADA

Open-source software backends, supervisory control systems, and data acquisition tools for industrial power monitoring.

- [FledgePower](https://github.com/fledge-power) — Open-source industrial IoT gateway and edge framework designed for electrical substations and power distribution automation.
- [Open-SCADA](https://github.com/openscada/openscada) — Open-source Supervisory Control and Data Acquisition system supporting industrial communication protocols.
- [OpenEMS (Open Energy Management System)](https://github.com/OpenEMS/openems) — Modular open-source framework for controlling, monitoring, and optimizing energy storage systems and renewable sites.

## Smart Metering & AMI Protocols

Communication protocols, data parsers, and software tools for Advanced Metering Infrastructure (AMI) and utility smart meters.

- [GXDLMSDirector](https://github.com/Gurux/Gurux.DLMS.python) — Open-source libraries and developer tools for parsing DLMS/COSEM utility smart meter protocols.
- [M-Bus Parser](https://github.com/rscada/libmbus) — Open-source C library for communicating with Meter-Bus (M-Bus) smart heat, water, and electricity meters.
- [Open-AMI-Engine](https://github.com/grid-telemetry) — Open-source microservice architecture for collecting, validating, and ingesting smart meter interval reads.

## Microgrids & DER Integration

Control algorithms, dispatch solvers, and vehicle-to-grid protocols for localized energy networks.

### Control & Dispatch Engines

- [REopt Lite](https://github.com/NREL/REopt-Lite-API) — NREL's optimization engine for sizing and operating renewable energy, battery storage, and microgrid assets.
- [Microgrid-Control-Core](https://github.com/open-microgrid) — Open-source controller framework for managing islanded microgrid frequency, voltage, and generator dispatch.

### EV & V2G Integration

- [Everest](https://github.com/EVerest/everest-core) — Open-source software stack for EV charging infrastructure supporting ISO 15118 vehicle-to-grid (V2G) communication.
